# yield-worktime-stats
產品製成率及工時統計系統

上傳最新的生產資料 Excel 檔（含「資料總表」與「工時」分頁），於瀏覽器本機解析並產生月度統計圖表，資料不會上傳到任何伺服器。

## 使用方式

1. 開啟 `index.html`（或 GitHub Pages 網址）。
2. 點擊或拖曳上傳生產資料 xlsx 檔。
3. 於產品清單勾選要分析的產品（最多 8 項同時比較），切換年份與指標檢視。

## 功能

- **工時統計**：每產品 1–12 月的「總生產時間(分)」「每鍋工時(分/鍋)」「每鍋人時(人分/鍋)」，圖上疊加去年年度平均參考線，高於／低於去年平均以深淺色區分。
- **製成率統計**：月度生產達成率（該月實際半成品總數 ÷ 預估總數），顯示 100% 目標線與 95%~105% 合理範圍帶，超出範圍的月份標紅。
- **多產品比較**：勾選多項產品時產生同軸比較折線圖。
- **KPI 卡片與數據表**：年度總時間、總鍋數、每鍋工時、每鍋人時、年度製成率；每張卡片可展開月度數據表。
- 支援深色模式與列印報表。

## 統計規則

- 月度僅計「足月」：資料起訖落在月中的月份、進行中的當月不列入統計。
- 排除列：專案／研發／無料號列、無實際生產數據列（含未來排程）、總生產時間為 0 的列。
- 「去年平均」：總生產時間取去年有生產足月的月平均；每鍋工時、每鍋人時、製成率取去年全年（足月）加總後相除。
- 工時分頁的無年份日期（如 `10/14`）以前後最近的完整日期為錨點推斷年份，可正確處理跨年。

## 技術

單一 `index.html` 靜態網頁，SheetJS（xlsx 0.18.5）解析 Excel、Chart.js 4.4.1 繪圖，函式庫已內建於 `vendor/`，不依賴外部 CDN。
